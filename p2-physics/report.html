P2 Physics: Eight Numerical Reproductions

Date: 2026-09-22

This report reproduces eight published physics results in Python and checks each one against its published value. The pipeline ran five stages in order: draft (write and run each script), verify (run each script twice and confirm identical output), referee (check the method, the error estimate, and the tolerance for each of the eight scripts), fix (apply the referee's numbered changes), and verify2 (re-run the fixed scripts twice and confirm identical output again).

Result: 8 of 8 targets pass. Two passes depend on a measured bias term: three_body before the fix, and fpu (unaffected by the fix). After the fix, three_body passes on 3x error alone.

Caveats

  • ising: the printed Tc supports 3 decimals of precision; extra printed digits beyond that are not supported by the error estimate.
  • lorenz: the asserted 1e-4 floor still dominates the tolerance over the measured 4.0e-5 Richardson bound.
  • kuramoto: runtime was 177 s and 211 s across the two verify2 runs, both under concurrent load, against a 180 s design limit.
  • fpu: the published value 157 is a reading from a plotted curve, not a stated number; the 95%-of-peak plateau level used for the bias term is a chosen constant.
  • poisson: the test function is an exact discrete eigenvector of the 5-point operator, so its order sequence is analytic by construction; the closed-form gate (1e-8 relative) is the real discriminating test.
  • kepler: block b's tolerance is now 7.9e-6 with the asserted 0.01 floor removed.
  • three_body: the initial data is the 14-digit form from Fenucci, arXiv:2201.01205.

Reproduction

Python 3.13.5, numpy 2.2.6, scipy 1.16.0.
Seeds where used: SEED=20260922 (ising, lorenz, kuramoto). three_body, fpu, feigenbaum, kepler, and poisson use no random number and set no seed.
Command: python scripts/<target>.py
Printed-line contract: MEASURED=, PUBLISHED=, ERROR_ESTIMATE=, TOLERANCE=, ABS_DIFF=, RUNTIME_S=, RESULT= (kepler also prints a _2-suffixed block for its second quantity).
