# Theorem 9 verdict: Radon–Nikodym theorem

VALID

The proof is von Neumann's L² proof for finite measures. It adds a σ-finite partition argument and a direct uniqueness argument. The statement in `t9-proof.md` matches item 9 of `theorems.md` exactly: the same hypotheses (μ, ν σ-finite, ν ≪ μ), the same codomain [0, ∞), and uniqueness μ-a.e. The referee checked each step. The referee found no gap in the existence chain or in the uniqueness chain. The referee found no missing hypothesis. There is one false sub-claim: the proof of Lemma C. Section 3 is the only place that uses Lemma C, and Section 3 is not necessary for the result (see minor point 1). Five minor points are listed after the checked steps. None of them changes the verdict.

## Key steps checked

1. **Partition (Section 1).** The sets A_i ∩ B_j are pairwise disjoint and cover Ω. μ and ν are finite on each set. The family is countable (ℕ × ℕ). Trace σ-algebras 𝓕_n ⊆ 𝓕 because Ω_n ∈ 𝓕. So μ_n, ν_n are finite measures and ν_n ≪ μ_n. This holds.
2. **Reassembly (Section 1).** The zero extension of f_n is 𝓕-measurable because {f_n > a} ∩ Ω_n ∈ 𝓕_n ⊆ 𝓕 and Ω \ Ω_n ∈ 𝓕. Each point lies in exactly one Ω_n, so f = Σ f_n has exactly one nonzero term at each point. Thus f is real-valued everywhere. The chain ν(E) = Σ ν(E ∩ Ω_n) = Σ ∫_E f_n dμ = ∫_E f dμ uses countable additivity and MCT on the partial sums. This holds.
3. **T is a bounded functional (Section 2.1).** ν ≤ λ = μ + ν set-wise. Lemma A then gives ∫|g| dν ≤ ∫|g| dλ. Cauchy–Schwarz with the pair (|g|, 1) gives the bound λ(Ω)^{1/2}‖g‖₂. This bound also shows that g ∈ L¹(ν). It also shows that T does not change when g changes on a λ-null set, so T is defined on equivalence classes (see minor point 3). Riesz representation then gives h ∈ L²(λ) with (2.1). This holds.
4. **0 ≤ h ≤ 1 λ-a.e. (Section 2.2).** The test sets are {h < 0} and {h > 1}. Their indicators are in L²(λ) because λ is finite. Lemma B gives strict inequalities that contradict ν ≥ 0 and ν ≤ λ. After the change on a λ-null set, the set is also μ-null and ν-null, because μ ≤ λ and ν ≤ λ. So later integrals against μ and ν do not change. This holds.
5. **Identity (2.2) (Section 2.3).** The identity uses (2.1) for the bounded function g, not for gh. Then it splits ∫gh dλ into ∫gh dμ + ∫gh dν. All integrands are bounded and all measures are finite, so each subtraction is between finite numbers. This holds (see minor point 2 for the unstated splitting fact).
6. **μ({h = 1}) = 0 (Section 2.4).** Put g = 1_A in (2.2). The left side is 0 and the right side is μ(A). Then ν(A) = 0 because ν ≪ μ. This is the only use of absolute continuity, and it is correct.
7. **Limit step (Section 2.5).** g_n is bounded because 0 ≤ h ≤ 1, so (2.2) applies to g_n. The telescoping identity (1 − h)Σ_{k=0}^{n} h^k = 1 − h^{n+1} is correct. On the left side, DCT applies with the dominating constant sup|g|, which is ν-integrable because ν is finite. On the right side, MCT applies because g ≥ 0 and h ≥ 0. The limit h/(1 − h) is finite at each point of A^c, because h < 1 there. So f: Ω → [0, ∞) everywhere, and f is measurable. This holds.
8. **Identification (Section 2.6).** Put g = 1_E in (2.5). ν(A) = 0 gives ν(E) = ν(E ∩ A^c). f = 0 on A gives ∫_{E∩A^c} f dμ = ∫_E f dμ. This holds.
9. **Uniqueness (Section 4).** The proof never subtracts ∞ − ∞. It restricts to A_{k,m} = {f ≥ f′ + 1/k} ∩ Ω_n ∩ C_m. On this set ν(A_{k,m}) ≤ ν(C_m) < ∞, so both integrals are finite and the subtraction is legitimate. Lemma B gives μ(A_{k,m}) = 0. Continuity from below (C_m ↑ Ω) and then the limit k → ∞ give μ({f > f′} ∩ Ω_n) = 0. Countable subadditivity and the symmetric argument complete the proof. The equivalence "f > f′ iff f ≥ f′ + 1/k for some k" needs f, f′ finite. The codomain [0, ∞) gives this. σ-finiteness of ν is used correctly: without it, uniqueness can fail. The restriction to Ω_n is unnecessary (C_m alone is sufficient), but it is harmless.
10. **Hypotheses.** σ-finiteness of μ is used in Section 1 and Section 4. σ-finiteness of ν is used in Section 1 (finite ν_n, so DCT applies in 2.5) and in Section 4. ν ≪ μ is used in Section 1 (ν_n ≪ μ_n) and in Section 2.4. No hypothesis is missing, and no hypothesis is unused.

## Minor points (not gaps)

1. **The proof of Lemma C is incorrect, and Section 3 is redundant.** Lemma C's proof says "by Lemma B, applied on {φ = ∞} with the constant value +∞, ∫φ dλ = ∞". Lemma B only gives ∫ > 0. It does not give ∫ = ∞. A correct proof is: ∫φ dλ ≥ c·λ({φ = ∞}) for every c > 0, so the integral is ∞. Section 3 is the only place that uses Lemma C. Section 3 is not necessary, because f = Σ f_n is already real-valued everywhere (key step 2). So the error does not change the theorem.
2. **Unstated fact: ∫φ d(μ + ν) = ∫φ dμ + ∫φ dν (Section 2.3).** Lemmas A–I do not include this fact. It is standard, and it has the same proof as Lemma A: indicators, then simple functions, then MCT. For bounded φ, it then extends by linearity to signed functions. The claim "the only external results used" (end of Section 0) is therefore not exactly true.
3. **Well-definedness of T on L² classes (Section 2.1).** The proof does not say that T gives the same value for two functions that are equal λ-a.e. This follows from the bound in the proof, because ν ≤ λ. Also, the proof does not say that a measurable real-valued representative of h is selected. Both steps are standard.
4. **Unstated identification in Section 1.** The proof applies the finite-case theorem on (Ω_n, 𝓕_n, μ_n). Then it treats ∫ f_n dμ_n on Ω_n and ∫ over Ω of the zero extension with respect to μ as equal. This is standard (indicators, simple functions, MCT), but the proof does not state it.
5. **Wording in Section 2.3.** The sentence "Substituting h = 1 − (1 − h) is not needed; instead…" is a leftover remark from drafting. It has no mathematical content.
