Rotating frames: the Park transform and the phase-locked loop

1. The opening problem

An inverter must inject current in step with a 50 Hz grid voltage that it can only sample, sample by sample, through an analogue-to-digital converter. It does not know the grid's phase in advance; it must estimate it continuously from the samples. After a disturbance elsewhere on the grid, the local voltage angle jumps by 30° almost instantaneously. Two questions follow. How does code find the new angle, given only three sampled phase voltages? And how long does that take once found?

Answer computed by this lesson. A phase-locked loop tuned for a natural frequency of 10 Hz (the lesson's "10 Hz bandwidth", defined in §2.1) and a damping ratio ζpll = 0.707 settles to within 2% of the jump in about 4/(ζpllωn,pll) = 0.090 s estimate, §2. Section 4 runs the loop on sampled data and measures 0.0779 s computed by the listing — close to the estimate, and the gap between the two is itself informative (§4.1).

2. The model

Park convention (shared rule 7, stated before the first d, q quantity is written). This lesson uses the amplitude-invariant Park transform, with the Clarke step carrying the factor 2/3. The d axis is defined to lie on the measured voltage, so once the phase-locked loop has locked, vq = 0 and vd carries the full voltage magnitude. Because the transform is amplitude-invariant rather than power-invariant, three-phase power in per unit is P = vdid + vqiq with no leading factor; the factor 3/2 that the same transform produces in SI units is derived in Exercise 1.

A balanced three-phase voltage set writes, with V the peak phase amplitude in per unit and θg the true grid angle in radians:

va = V cos(θg),  vb = V cos(θg−120°),  vc = V cos(θg+120°).

The Clarke transform maps the three phase quantities to two in a frame fixed to the stator (the "stationary" or αβ frame):

vα = (2/3)(va − ½vb − ½vc) = V cos(θg),  vβ = (1/√3)(vb − vc) = V sin(θg).

For a balanced set the two Clarke components are already only two numbers, but they still swing at 50 Hz: vα and vβ trace a circle in the plane, one full turn per grid cycle. The Park transform then rotates that plane by the phase-locked loop's own angle estimate θpll, converting the circling vector into two numbers that stop moving once the frame's rotation matches the vector's rotation:

vd = vαcos(θpll) + vβsin(θpll) = V cos(θg − θpll),

vq = −vαsin(θpll) + vβcos(θpll) = V sin(θg − θpll).

derived here. Figure 5.1 shows both sides of this: three swinging phase voltages on the left, and the constant pair (vd, vq) = (1.000000, 0.000000) pu on the right, once the loop's angle matches the grid's. Evaluating clarke_park from §4 with θpll = θg exactly gives (1.0000000000000002, 1.7×10−16) pu, which is floating-point round-off. Inside the running loop the two angles agree only approximately: at t = 0.099 s, before the jump, |vq| = 2.5×10−4 pu.

3. The key derivation

Near lock, θg − θpll is small, so vq = Vsin(θg−θpll) ≈ V(θg−θpll). The gain from angle error to vq is therefore Kpll = V on a stiff grid, where the converter's own current does not move the terminal voltage (Lesson 6 removes this assumption). derived here This is the synchronous-reference-frame PLL's error signal: it needs no separate phase detector, because vq already vanishes exactly at lock.

The PI controller and the integrator that turns a frequency estimate into an angle estimate close the loop:

ωpll = ω0 + kp,pllvq + ki,pll∫vq dt,   dθpll/dt = ωpll.

Substituting vq ≈ Kplle, with the angle error e = θg−θpll, and differentiating once to eliminate the integral gives a linear, second-order homogeneous equation in e whenever the grid's own frequency is not itself moving:

s² + Kpllkp,plls + Kpllki,pll = 0.

derived here Matching coefficients against the standard form s² + 2ζωns + ωn² = 0 gives:

ωn,pll = √(Kpllki,pll),   ζpll = Kpllkp,pll / (2ωn,pll).

Tuning. For a target ωn,pll = 2π×10 = 62.8319 rad/s and ζpll = 0.707 on a stiff grid (Kpll = 1):

ki,pll = ωn,pll² / Kpll = 3947.8418 1/s² ≈ 3948 1/s²,   kp,pll = 2ζpllωn,pll / Kpll = 88.8442 1/s ≈ 88.84 1/s.

computed by the listing §4 uses these exact gains (before rounding) throughout.

4. The code

The listing below samples a balanced 50 Hz three-phase voltage at 10 kHz, runs the PI loop with the gains from §3, jumps the grid angle by 30° at t = 0.1 s, and steps the grid frequency to 50.5 Hz at t = 0.4 s. Following the convention set in Lesson 3, the two internal integrators (the PI integral state and the angle itself) use semi-implicit Euler, not forward Euler: at each sample the integral state is advanced first, then the frequency estimate, then the angle — never the other order. derived here

"""SRF-PLL: lock time after a phase jump, error after a freq step."""
import math

FS = 10000.0
DT = 1.0 / FS
OMEGA0 = 2.0 * math.pi * 50.0
V = 1.0
ZETA = 0.707
WN = 2.0 * math.pi * 10.0
KP = 2.0 * ZETA * WN / V
KI = WN * WN / V
JUMP_T, JUMP = 0.1, math.pi / 6
STEP_T, DHZ = 0.4, 0.5


def theta_grid(t):
    th = OMEGA0 * t
    if t >= JUMP_T:
        th += JUMP
    if t >= STEP_T:
        th += 2.0 * math.pi * DHZ * (t - STEP_T)
    return th


def clarke_park(va, vb, vc, theta_pll):
    valpha = (2.0 / 3.0) * (va - 0.5 * vb - 0.5 * vc)
    vbeta = (1.0 / math.sqrt(3.0)) * (vb - vc)
    vd = valpha * math.cos(theta_pll) + vbeta * math.sin(theta_pll)
    vq = -valpha * math.sin(theta_pll) + vbeta * math.cos(theta_pll)
    return vd, vq


def run(kp, ki, t_end=0.6):
    theta_pll, z = 0.0, 0.0
    n = int(round(t_end / DT))
    err, t_hist = [], []
    for k in range(1, n + 1):
        t = k * DT
        tg = theta_grid(t)
        va = V * math.cos(tg)
        vb = V * math.cos(tg - 2 * math.pi / 3)
        vc = V * math.cos(tg + 2 * math.pi / 3)
        vd, vq = clarke_park(va, vb, vc, theta_pll)
        z += DT * vq  # semi-implicit Euler: integral first, then angle
        omega_pll = OMEGA0 + kp * vq + ki * z
        theta_pll += DT * omega_pll
        e = math.atan2(math.sin(tg - theta_pll), math.cos(tg - theta_pll))
        err.append(e)
        t_hist.append(t)
    return t_hist, err


def settling_time(t_hist, err, band, window_end=STEP_T):
    band_abs = band * JUMP
    final_val = err[int(round(window_end / DT)) - 2]
    last_out = None
    for i, (t, e) in enumerate(zip(t_hist, err)):
        if JUMP_T <= t < window_end and abs(e - final_val) > band_abs:
            last_out = i
    return 0.0 if last_out is None else t_hist[last_out + 1] - JUMP_T


if __name__ == "__main__":
    t_hist, err = run(KP, KI)
    ts = settling_time(t_hist, err, 0.02)
    i1 = int(round((STEP_T - DT) / DT)) - 1
    i2 = int(round((0.6 - DT) / DT)) - 1
    print("omega_n_pll = %.4f rad/s" % WN)
    print("k_p_pll = %.4f 1/s, k_i_pll = %.4f 1/s^2" % (KP, KI))
    print("settling time (2%% of 30 deg jump) = %.4f s" % ts)
    print("angle error just before freq step = %.6f rad" % err[i1])
    print("angle error at end (after freq step)  = %.6f rad" % err[i2])
    w_new = OMEGA0 + 2.0 * math.pi * DHZ
    print("residual beyond -omega*DT bias: before = %.2e rad, "
          "after = %.2e rad" % (err[i1] + OMEGA0 * DT, err[i2] + w_new * DT))

4.1 Reading the settling-time number

The measured settling time, 0.0779 s, is 13.5% below the 0.0900 s envelope estimate (0.0779/0.0900 = 0.865) 4/(ζpllωn,pll) quoted in §1. computed by the listing The gap is the estimate's own approximation, not a modelling error: "4" approximates −ln(0.02) = 3.912 (the number of time constants exp(−ζpllωn,pllt) needs to fall to 2%), and it ignores the response's specific oscillatory shape — this loop starts a phase jump with a non-zero initial rate of change of the error (de/dt(0) = −2ζpllωn,pllΔθ, not zero), which is not the textbook unit-step case the envelope formula is built for. Both numbers describe the same lock: use the formula for a quick estimate before code exists, use the listing's number once it does.

4.3 The steady angle error after the frequency step

Just before the 0.5 Hz frequency step (t = 0.4 s−Δt), the angle error is −0.031416 rad; 200 ms after the step (t = 0.6 s−Δt) it is −0.031725 rad, a change of 0.000309 rad (0.0177°). computed by the listing Neither value is a control error. The listing computes e after it advances θpll, so it compares the grid angle at sample k with the loop's angle for sample k+1. When the Park angle is exactly on the grid angle at sample k, that comparison reads −ωgΔt, where ωg is the grid's angular frequency. Before the step this is −314.159265 rad/s × 1×10−4 s = −0.031416 rad; after the step it is −2π×50.5 rad/s × 1×10−4 s = −0.031730 rad. The bias moves by 0.000314 rad, which accounts for the observed change. The last output line removes the bias: the residual angle error is 2.84×10−8 rad before the step and 4.84×10−6 rad 200 ms after it, and the second value is still decaying toward zero. A type-2 loop (two integrators: the PI's own integral and the angle integrator) tracks a frequency step with zero steady angle error, as Exercise 5 predicts.

5. What the model captures and what it misses

The model captures: a balanced, undistorted three-phase voltage; amplitude-invariant Clarke and Park transforms; a linearised, second-order PLL whose gains follow directly from a target bandwidth and damping ratio; and a stiff grid, meaning the converter's own injected current does not move the terminal voltage it is trying to track — Lesson 6 removes exactly this assumption and replaces Kpll = V with a gain that falls as the grid weakens. It also omits any measurement filter (no anti-alias or notch stage before the Park transform).

Unbalance is named, not modelled beyond Exercise 3: a negative-sequence component appears in the rotating frame at twice grid frequency (100 Hz at 50 Hz), because a phasor rotating at −θg viewed from a frame rotating at +θpll ≈ +θg appears to rotate at −2θg, producing a ripple on vq rather than a constant offset. Exercise 3 measures that ripple's amplitude directly.

6. Exercises

Exercise 1 (Derivational)

Show that the three-phase instantaneous power in SI units is p = 1.5(vdid + vqiq) with the amplitude-invariant transform, and that the factor 1.5 vanishes in per unit.

Target

In SI, p = vaia + vbib + vcic. The inverse amplitude-invariant Clarke map is va = vα + v0, vb = −½vα + (√3/2)vβ + v0, vc = −½vα − (√3/2)vβ + v0, and the same for the currents, with v0 the zero-sequence component. Multiply and sum. The vαiα coefficient is 1 + ¼ + ¼ = 1.5; the vβiβ coefficient is ¾ + ¾ = 1.5; the vαiβ and vβiα coefficients are −√3/4 + √3/4 = 0; the zero-sequence terms give 3v0i0. In a three-wire system i0 = 0 (and a balanced set has v0 = 0), so p = 1.5(vαiα + vβiβ) = 1.5(vdid + vqiq), because the Park rotation preserves the dot product. Per-unit power uses Sbase = 1.5 VbaseIbase, with Vbase and Ibase the peak phase voltage and current (so Sbase equals 3 × RMS phase voltage × RMS phase current), so dividing both sides by Sbase cancels the factor and leaves P = vdid + vqiq in per unit — the per-unit bases absorb it, as shared rule 7 states.

Exercise 2 (Derivational)

Show that Kpll = dvq/dθerror at lock equals V.

Target

vq = Vsin(θerror) with θerror = θg−θpll. dvq/dθerror = Vcos(θerror), which at lock (θerror = 0) equals Vcos(0) = V. On a stiff grid at rated voltage V = 1 pu, so Kpll = 1.

Exercise 5 (Conceptual)

Why does a frequency step leave zero steady angle error but a frequency ramp does not?

Target

A frequency step is a ramp in angle. This PLL is a type-2 loop (two integrators in the forward path: the PI's own integral term, and the angle integrator dθpll/dt = ωpll), and a type-2 loop tracks a ramp input with zero steady-state error — confirmed numerically in §4.3, where the residual angle error after the frequency step, with the listing's −ωΔt bias removed, is 4.84×10−6 rad. A frequency ramp is a parabola in angle (angle proportional to t²), and tracking a parabola with zero steady error needs a third integrator in the forward path, which this loop does not have; a type-2 loop tracks a parabolic input with a bounded but non-zero steady error instead. For a frequency ramp of R rad/s², the final-value theorem applied to E(s) = s²/(s² + Kpllkp,plls + Kpllki,pll) · R/s³ gives ess = R/(Kpllki,pll) = R/ωn,pll².
