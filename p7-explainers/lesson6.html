Following on a weak grid: a current bound and a vanishing gain

Lesson 6 · grid-following converter behind j Xg · short-circuit ratio and the phase-locked loop · Example 2.1 of P1

Opening problem. A 200 MVA solar plant connects at a point where the grid's short-circuit level is 300 MVA. Can it export its full rating at unity power factor with a standard grid-following controller? This lesson computes the answer: no. The short-circuit ratio is 1.5, the terminal voltage sags to 0.7454 pu, and this model's maximum deliverable power at that strength is 0.750 pu — below the plant's own 1.0 pu rating even before the phase-locked loop's dynamics are considered. The cited literature warns that the true limit is lower still [S07, S08 — verify].

1. The model

A grid-following converter regulates its own output current; it does not set the voltage at its terminals the way a synchronous machine or a grid-forming converter does. To find that current's phase, the converter runs a phase-locked loop (PLL): a control loop that measures the terminal voltage and drives an internal angle θp to track the angle of that voltage. Model the rest of the grid, seen from the point of connection, as an ideal voltage source Vg at angle 0 behind a purely inductive Thévenin reactance Xg — the same idealisation Lesson 2 used for the “infinite bus,” except here the reactance is not negligible. The converter itself is an ideal current source: it injects a current of magnitude Id exactly on its own PLL d-axis, with no reactive current (Iq = 0) — the standard unity-power-factor grid-following control target. Because the inner current loop is assumed infinitely fast (an assumption this lesson returns to in Section 6), the current is taken as already equal to its commanded value at every instant.

Define the short-circuit ratio:

SCR = Ssc / Srated

where Ssc is the short-circuit level (in MVA) of the grid at the point of connection and Srated is the converter's own rated capacity. On the converter's own per-unit base, with a purely inductive grid, this ratio and the grid reactance are reciprocals:

Xg = 1 / SCR   (pu, converter base)

A stiff grid (SCR ≫ 1, so Xg small) barely reacts to the converter's current. A weak grid (SCR close to 1, so Xg close to 1 pu) reacts a great deal — and Section 3 shows that “a great deal” has a hard edge.

2. Derivation: the loop equation and the existence bound

Put the grid voltage phasor at angle 0: Vg∠0. The converter's current sits on its own PLL d-axis, at angle θp measured from that same fixed reference: I = Id∠θp. The terminal voltage, seen at the fixed grid reference, is

Vt = Vg + j Xg I

Now express that same phasor in the PLL's own rotating d-q frame — the frame the loop actually measures in — by multiplying by e−jθp:

vd + j vq = Vt e−jθp = Vgcos(θp) + j[XgId − Vgsin(θp)]

Reading off real and imaginary parts:

vd = Vgcos(θp)    vq = XgId − Vgsin(θp)

A phase-locked loop drives its own tracking error to zero, and for this architecture the tracking error is vq itself: the loop adjusts θp until vq = 0. Lock therefore requires

sin(θ0) = XgId / Vg

and because sine is bounded by 1, a real solution θ0 exists if and only if

XgId ≤ Vg    i.e.    Id ≤ SCR·Vg (pu)

This is the existence bound, and its shape matters: it is a ceiling on current, not on power. Nothing in the algebra above mentions power at all — the bound falls straight out of requiring a real angle, before any power is computed.

At a locked point, the terminal voltage magnitude is |Vt| = √(vd² + vq²) = vd (since vq = 0) = Vgcos(θ0). Delivered real power is P = vdId, and substituting the lock condition sin(θ0) = XgId/Vg so that Id = Vgsin(θ0)/Xg gives, after using vd = Vgcos(θ0):

P = Vgcos(θ0)·Vgsin(θ0)/Xg = (Vg² / (2 Xg)) sin(2θ0)

a sine of twice the angle, which peaks at θ0 = 45° with value Pmax = Vg²/(2Xg) = SCR·Vg²/2 (using Xg = 1/SCR), and then falls back toward zero as θ0 continues from 45° to 90°. At the current bound itself, where θ0 = 90°, the model's delivered power is zero. Delivered power is therefore not monotonic in current on a weak grid: it rises with Id until Id = SCR·Vg·sin(45°) = 0.707 SCR·Vg, then falls.

Now linearise the loop around lock. Differentiate vq(θp) = XgId − Vgsin(θp) with respect to θp: the term XgId does not depend on θp at all, so it drops out entirely, leaving

d(vq)/d(θp) = −Vgcos(θ0)

Every parameter of the physical setup — grid strength, converter current, all of it — has collapsed into this one scalar. Define

Kpll = Vgcos(θ0)

which is the same number as the terminal voltage magnitude computed two paragraphs above, because both equal vd at lock. With Lesson 5's PI-loop gains kp_pll, ki_pll, the standard second-order result for a loop with this small-signal gain is

ωn_pll = √(Kpll·ki_pll)    ζpll = Kpllkp_pll / (2ωn_pll) = 0.707√Kpll

(the last equality holds specifically for gains tuned so that ζpll = 0.707 at Kpll = 1, the case used throughout this lesson: then kp_pll/(2√ki_pll) = 0.707). Both ωn_pll and ζpll shrink toward zero exactly as Kpll does, and Kpll shrinks toward zero exactly at the current bound — the designer changed nothing, and the grid moved the loop.

Compare this directly with Lesson 2's synchronizing torque coefficient: Ks = (E′V/X)cos(δ0) and Kpll = Vgcos(θ0) have the same structure — an amplitude times the cosine of the operating angle — and both vanish at the same angle, 90°. The amplitudes differ: Ks carries the factor 1/X, while Kpll carries only Vg, and Xg enters Kpll only through θ0. One measures a synchronous machine's restoring torque; the other measures a converter's phase-tracking bandwidth; the algebra that makes each go to zero at the same angle is identical.

3. Numbers: Example 2.1 and the sweep

Example 2.1 of P1 fixes SCR = 1.2, so Xg = 1/1.2 = 0.8333 pu, with Vg = 1 pu and Id = 1 pu. Solving sin(θ0) = 0.8333 gives θ0 = 56.44°. The terminal voltage and Kpll are both Vgcos(56.44°) = 0.5528 pu, and delivered power P is the same number, 0.5528 pu, against this model's Pmax = SCR·Vg²/2 = 0.600 pu.

A note on two versions of the PLL gains, exactly as Lesson 2 flagged for Ks: the P1 plan prints ωn_pll = 46.72 rad/s (7.44 Hz) with kp_pll = 88.86. This lesson's probe (Section 4) uses ki_pll = (2π×10)² = 3947.8 1/s² and kp_pll = 2×0.707×62.83 = 88.84 1/s, and with those it computes ωn_pll = 46.71 rad/s = 7.435 Hz and ζpll = 0.5256, down from ζpll = 0.707 at Kpll = 1. The two kp_pll values come from two inputs: the plan's 88.86 corresponds to ζ = 1/√2 = 0.7071, and the probe's 88.84 to ζ = 0.707 exactly. The two ωn_pll values, 46.72 and 46.71 rad/s, are two roundings of the unrounded 46.715 rad/s. This lesson prints and uses only the probe's own values.

Between SCR = 3 and SCR = 1.2, P falls by 41% (0.9428 to 0.5528 pu) and Pmax falls by 60% (1.500 to 0.600 pu). P never exceeds Pmax, and the two are equal at SCR = √2 = 1.414, where θ0 = 45°; at SCR = 1.5 the gap is only 0.0046 pu. Below SCR = 1.414 the operating point is on the falling side of the sin(2θ0) curve: rated current delivers less power than a smaller current would. At SCR = 0.95, XgId = 1.0526 already exceeds Vg = 1, so no real θ0 solves the lock condition at all: this is not a small number, it is the absence of a number, and Section 5's simulation shows what that looks like in time.

The omission that matters most. This model has no reactive support: Iq is fixed at zero throughout. That is why the terminal voltage falls all the way to Vgcos(θ0). A real plant that instead holds its terminal voltage near 1 pu by injecting reactive current reaches a higher figure, Pmax = SCR·Vg|v|, quoted in the cited literature [S07, S08 — verify]. This lesson's numbers are a lower bound set by a control choice (unity power factor), not a law of physics.

4. Code: solving for non-existence, and watching the runaway

The listing below (lesson6_weak_grid.py, standard library only, 99 lines, reproduced verbatim) does two things. Part 1 finds θ0 for each SCR in the sweep by bisection on vq(θ) = XgId − Vgsin(θ) over [0, π/2]: when vq is positive even at θ = π/2 (the largest sin(θ) can be), the bisection function returns None and the script prints “no steady state” instead of a number — a root finder finding no root, exactly because none exists. Part 2 integrates the full nonlinear PI loop, dθp/dt = kp_pllvq + z, dz/dt = ki_pllvq, by fixed-step RK4 (dt = 1×10−4 s) at SCR = 1.2 and SCR = 0.95, with vq recomputed from the current θp at every stage of every step, exactly as the loop equation of Section 2 defines it. 

"""Weak-grid current-source PLL: existence bound and loop runaway.

Part 1: bisection for theta_0 over a range of SCR, plus PLL gain and
damping. Part 2: RK4 integration of the nonlinear PI-PLL loop, showing
lock at SCR = 1.2 and loss of synchronism at SCR = 0.95.

Swing/PLL convention matches Lesson 2/5: gains named k_p_pll, k_i_pll.
Stdlib only. Run: python lesson6_weak_grid.py
"""
import math

V_G = 1.0
I_D = 1.0
K_I_PLL = (2.0 * math.pi * 10.0) ** 2
K_P_PLL = 2.0 * 0.707 * (2.0 * math.pi * 10.0)


def v_q(theta_p, x_g):
    return x_g * I_D - V_G * math.sin(theta_p)


def bisect_theta0(x_g, lo=0.0, hi=math.pi / 2.0, tol=1e-10):
    if v_q(hi, x_g) > 0.0:
        return None
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if v_q(mid, x_g) > 0.0:
            lo = mid
        else:
            hi = mid
        if hi - lo < tol:
            break
    return 0.5 * (lo + hi)


def part1():
    print("SCR    theta0(deg) K_pll   P       P_max   "
          "omega_n(rad/s) zeta")
    for scr in (10.0, 3.0, 2.0, 1.5, 1.2, 1.05, 0.95):
        x_g = 1.0 / scr
        theta0 = bisect_theta0(x_g)
        if theta0 is None:
            print("%5.2f  no steady state (X_g I_d=%.4f > V_g)"
                  % (scr, x_g * I_D))
            continue
        k_pll = V_G * math.cos(theta0)
        p = (V_G ** 2 / (2.0 * x_g)) * math.sin(2.0 * theta0)
        p_max = scr * V_G ** 2 / 2.0
        omega_n = math.sqrt(k_pll * K_I_PLL)
        zeta = k_pll * K_P_PLL / (2.0 * omega_n)
        print("%5.2f  %9.2f  %.4f  %.4f  %.3f   %7.2f       %.4f"
              % (scr, math.degrees(theta0), k_pll, p, p_max,
                 omega_n, zeta))


def rk4_step(state, dt, x_g):
    def deriv(s):
        theta_p, z = s
        vq = v_q(theta_p, x_g)
        return (K_P_PLL * vq + z, K_I_PLL * vq)

    k1 = deriv(state)
    s2 = tuple(state[i] + 0.5 * dt * k1[i] for i in range(2))
    k2 = deriv(s2)
    s3 = tuple(state[i] + 0.5 * dt * k2[i] for i in range(2))
    k3 = deriv(s3)
    s4 = tuple(state[i] + dt * k3[i] for i in range(2))
    k4 = deriv(s4)
    return tuple(state[i] + (dt / 6.0) * (k1[i] + 2 * k2[i]
                 + 2 * k3[i] + k4[i]) for i in range(2))


def simulate(scr, t_end=0.5, dt=1e-4):
    x_g = 1.0 / scr
    state = (0.0, 0.0)
    trace = [(0.0, 0.0)]
    t = 0.0
    n = int(t_end / dt)
    for _ in range(n):
        state = rk4_step(state, dt, x_g)
        t += dt
        trace.append((t, state[0]))
    return trace


def part2():
    for scr in (1.2, 0.95):
        trace = simulate(scr)
        t_end, theta_end = trace[-1]
        print("SCR=%.2f  theta_p(t=%.2fs)=%.4f rad (%.2f deg)"
              % (scr, t_end, theta_end, math.degrees(theta_end)))


if __name__ == "__main__":
    part1()
    print()
    print("k_p_pll=%.2f  k_i_pll=%.1f" % (K_P_PLL, K_I_PLL))
    print()
    part2()

5. A second look: where the poles actually go

The existence bound of Section 2 is a static condition: it says whether a locked point exists, not how the loop behaves as it approaches that limit. The linearised loop's characteristic equation is s² + Kpllkp_plls + Kpllki_pll = 0, whose roots are s = −ζpllωn_pll ± jωn_pll√(1−ζpll²). Substituting ζpllωn_pll = Kpllkp_pll/2 shows the real part is −Kpllkp_pll/2: negative for every Kpll > 0, and it only reaches zero in the limit Kpll → 0, which is the bound itself.

With the fixed gains of Section 4 (kp_pll = 88.84, ki_pll = 3947.8), the pole pair at six values of Kpll from 1.0 down to 0.1:

So the static bound alone does not explain an oscillatory instability observed before it is reached (at an SCR above the bound's value): this root locus only shows the poles becoming slow and lightly damped, never unstable by themselves. The literature attributes an oscillatory instability seen in practice below the static bound to phase-locked-loop and current-loop interaction — the inner current loop that Section 1 assumed infinitely fast is not, in fact, infinitely fast — a mechanism this lesson cites but does not derive [S08 — verify].

6. Model limits

Four assumptions carry the whole of this lesson, and each one is a simplification, stated so an editor or a reader can see exactly where the model would need to grow to answer a harder question:

  • Ideal current source. The converter's inner current loop is treated as infinitely fast, so the commanded Id is taken as delivered instantly. Section 5's cited result is precisely about what happens when that assumption is relaxed.
  • No reactive support. Iq = 0 throughout, which is why the terminal voltage is allowed to fall as far as Vgcos(θ0). This is a control choice this lesson's numbers are conditioned on, not a physical ceiling — the warning box in Section 3 states the higher figure a plant with reactive support could reach.
  • Purely inductive grid. Xg is treated as a pure reactance with SCR = 1/Xg; a grid with resistance or with generation of its own behind the point of connection is not this model.
  • One converter. The model has exactly one current source behind exactly one Thévenin impedance. A fleet of such converters adds no synchronizing coefficient and no inertia to the grid they sit on, because a current source contributes no Thévenin voltage source and so no short-circuit power — SCR for the plant already connected does not rise just because more grid-following plant joins nearby (this is also the answer to Exercise 5, below).

The observed instability before the static bound is reached is a cited result, not one derived in this lesson: Section 5 shows the linear root locus staying in the left half-plane all the way to Kpll = 0.1, so whatever mechanism produces an oscillatory instability at a similarly weak SCR must come from outside this single-loop linear picture — named here as phase-locked-loop and current-loop interaction, cited [S08 — verify] and left for a later lesson to derive.

7. Exercises

1. (Conceptual) The opening problem

A 200 MVA solar plant connects where the grid's short-circuit level is 300 MVA. State the short-circuit ratio and say whether the plant can export its full rating at unity power factor under this lesson's model.

Answer target

SCR = 300/200 = 1.5, so Xg = 1/1.5 = 0.6667 pu. At Id = 1 pu, sin(θ0) = 0.6667, so θ0 = 41.81°. Terminal voltage and Kpll are both Vgcos(41.81°) = 0.7454 pu, and delivered power P = 0.7454 pu. This model's maximum at this SCR is Pmax = SCR·Vg²/2 = 0.750 pu. So the plant cannot export 1.0 pu (its full rating) without reactive support to hold the terminal voltage up — the answer stated in the opening problem.

2. (Derivational)

Show that every term of d(vq)/d(θp) except the one from Vgsin(θp) is identically zero, so that at lock grid strength enters the loop through one scalar.

Answer target

vq(θp) = XgId − Vgsin(θp). Differentiating with respect to θp: d(XgId)/d(θp) = 0, because XgId does not depend on θp at all — it is fixed by the grid strength and the commanded current, not by the PLL's own angle. The only surviving term is d(−Vgsin(θp))/d(θp) = −Vgcos(θp), evaluated at lock (θp = θ0) to give −Vgcos(θ0) = −Kpll. The inputs that vary with grid strength or converter current (Xg, Id) drop out of the derivative at every θp, not only at lock; only Vg and θ0 remain, and θ0 itself was set by XgId one step earlier. So grid strength affects the loop's local dynamics only by moving θ0, and it does that through exactly one number, Kpll.

3. (Computational)

Sweep SCR from 1.01 to 10 and find where ζpll first falls below 0.3.

Answer target

Analytically, ζpll = 0.7071√Kpll = 0.300 at Kpll = 0.180, which is θ0 = arccos(0.180) = 79.6°, giving SCR = 1/sin(79.6°) = 1.017. This lesson's sweep (lesson6_exercises.py, resolution ΔSCR = 0.001, scanning down from SCR = 10) returns the first point below the threshold at SCR = 1.016, ζpll = 0.2973, Kpll = 0.177, θ0 = 79.8° — one step of the 0.001 grid past the analytic crossing, which is exactly the resolution used.

4. (Computational)

Retune the PLL so that ζpll = 0.707 at SCR = 1.2, then run the retuned loop at SCR = 10.

Answer target

At SCR = 1.2, Kpll = 0.5528. To recover ζpll = 0.707 at that Kpll, divide both original gains by 0.5528: kp_pll = 88.84/0.5528 = 160.7 1/s, ki_pll = 3947.8/0.5528 = 7141.9 1/s² (this lesson's probe, lesson6_exercises.py). At SCR = 10, Kpll = 0.9950, so ωn_pll = √(0.9950×7141.9) = 84.3 rad/s and ζpll = 0.9950×160.7/(2×84.3) = 0.949 — a loop that now runs both faster and more heavily damped than the SCR = 1.2 design point, because the same gains that were tuned for the weak grid become comparatively too aggressive once the grid stiffens back up. Retuning for the worst case trades away performance everywhere else.

5. (Conceptual)

Why does adding more grid-following plant not raise SCR for the plant already there?

Answer target

SCR is set by the Thévenin sources behind the point of connection: it measures how much short-circuit current a fault there would draw from voltage sources upstream. A grid-following converter is modelled, in this lesson and in general, as an ideal current source — it has no internal Thévenin voltage source of its own and contributes no short-circuit power. Adding another such converter nearby adds current-source capacity, not voltage-source capacity, so the short-circuit level Ssc seen at the original plant's point of connection is unchanged, and its SCR = Ssc/Srated does not rise.
