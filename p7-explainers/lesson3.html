When the Integrator Lies: Step Size and False Instability

Lesson 2 built a single machine against an infinite bus and proved, by computing its eigenvalues, that a small disturbance decays. This lesson simulates the same machine and watches it fall out of step. Neither the machine nor Lesson 2's proof is wrong. The numerical method is. This lesson shows how to see that before trusting a plot.

1. Opening problem

A programmer takes the single-machine-infinite-bus (SMIB) model from Lesson 2 — inertia constant H = 3.5 s, damping K_D = 2 pu, internal voltage E′ = 1.1 pu behind reactance X = 0.65 pu against an infinite bus at Vinf = 1.0 pu, mechanical power Pm = 0.8 pu — and steps Pm from 0.8 pu to 0.85 pu. Lesson 2 linearised this machine at its equilibrium angle δ0 = 28.21° and found the eigenvalues λ = −0.1429 ± j8.9607 s−1: a decaying oscillation at 1.43 Hz, period about 0.7 s — inside the 0.7 Hz–2 Hz band reported for local plant modes [S01, Kundur 1994, Power System Stability and Control, §12.1 — verify]. A negative real part means stable.

The programmer integrates with forward Euler at a step h = 10 ms — a number that looks safely small next to a 0.7 s period, only 1.4% of it. The angle δ(t) does not settle near a new equilibrium. It swings wider on every cycle and, at t = 16.93 s, passes 180°: by the usual convention this means the machine has lost synchronism. Lesson 2 proved this machine is stable. The simulation says it is not. One of the two is wrong, and it is not the physics. This lesson derives exactly which step sizes forward Euler can be trusted at for this eigenvalue, shows two integrators that do not have the problem, and gives the check a programmer can run in seconds — before believing any transient plot — instead of running the simulation twice as long "to be sure".

2. Model: the linear test equation and three integrators

Near an equilibrium, Lesson 2's swing equation

2H d(Δω)/dt = P_m - P_e - K_D Δω
      dδ/dt = ω_0 Δω

(rotor angle δ in rad, per-unit speed deviation Δω, synchronous speed ω0 = 2π·60 = 376.991 rad/s, electrical power Pe = Pmax sinδ, and damping K_D, never written D) linearises to dx/dt = Ax, whose eigenvalues are a complex-conjugate pair λ = σ ± jωd. Any single mode of that linear system obeys the scalar linear test equation

dx/dt = λx,      x(t) = x(0) e^(λt).

Here σ (1/s) is the physical decay rate — negative means the mode dies out — and ωd (rad/s) is the damped oscillation frequency. A numerical method does not evaluate eλt; it builds an approximation to it, one step at a time, and the three methods this lesson compares build it three different ways:

  • Forward Euler: x_(k+1) = x_k + h·f(x_k). Applied to the test equation: x_(k+1) = (1 + hλ)x_k.
  • Semi-implicit (symplectic) Euler: update the speed deviation first with the old angle, then the angle with the new speed deviation: Δω_(k+1) = Δω_k + h(P_m − P_max sinδ_k − K_DΔω_k)/(2H), δ_(k+1) = δ_k + hω_0Δω_(k+1). It costs the same one function evaluation as forward Euler.
  • RK4: the classical fourth-order Runge–Kutta method, four function evaluations per step, with local truncation error O(h5) per step and global error O(h4) for a smooth right-hand side.

For any of these, one step multiplies the current error mode by a number R(hλ) called the amplification factor. The true solution multiplies by eλh each step, whose magnitude is eσh < 1 whenever σ < 0. A method is linearly stable at step h exactly when |R(hλ)| < 1. Being stable and being accurate are different claims: a stable method can still multiply the true answer by the wrong factor at every step, as §3 shows numerically.

3. Derivation: amplification, the stability limit, and a conserved energy

3.1 Forward Euler's amplification factor

From x_(k+1) = (1 + hλ)x_k, the amplification factor is R = 1 + hλ. With λ = σ + jωd,

|1 + hλ|² = (1 + hσ)² + (hω_d)².

Using Lesson 2's base-point eigenvalue σ = −0.1429 1/s, ωd = 8.9607 rad/s, at h = 0.01 s: |1 + hλ| = 1.00258, a number just over 1. Over one second that multiplies the amplitude by 1.002581/0.01 = eg where the equivalent continuous growth rate is g = ln(1.00258)/0.01 = +0.258 s−1 — positive — against the true physical decay rate of −0.143 s−1. Over 10 s, forward Euler multiplies the oscillation amplitude by 1.002581000 = 13.2; the true system multiplies it by e−1.429 = 0.240. The method has not just lost accuracy: it has flipped the sign of the trend. This is false instability, introduced by the step, not by the machine. Every number in this paragraph is printed by lesson3_euler_drift.py in §4.

3.2 The stability limit and why "stable" is not "accurate"

Solving |1 + hλ| < 1 for h (expand the square to get 2hσ + h²|λ|² < 0, then divide by h > 0; no approximation is made) gives exactly

h < h_crit = -2σ / |λ|²

With σ = −0.1429 and |λ|² = σ² + ωd² = 80.32, hcrit = 0.2857/80.32 = 0.00356 s = 3.56 ms. Above this step, forward Euler is unstable for this eigenvalue regardless of how small the physical time constant looks. But hcrit only guarantees decay, not correctness: at h = 1 ms (well under the 3.56 ms limit), forward Euler still multiplies the 10 s amplitude by 0.358, not the true 0.240 — stable, and still wrong by close to 50%. A programmer who only checks "does it decay?" and stops there has under-checked the method.

3.3 A conserved energy for the undamped machine

Set KD = 0. Multiply the swing equation's speed-deviation row by ω0Δω and substitute dδ/dt = ω0Δω:

2Hω_0Δω d(Δω)/dt = (P_m - P_max sinδ)ω_0Δω
H d(ω_0Δω²)/dt = (P_m - P_max sinδ) dδ/dt
d/dt [ Hω_0Δω² - P_mδ - P_max cosδ ] = 0.

Call the bracketed quantity W = Hω0 Δω² − Pmδ − Pmaxcosδ. With damping restored, the same steps give dW/dt = −KD ω0Δω² ≤ 0, so W is exactly conserved by the true dynamics when KD = 0 (Exercise 2 asks for this derivation again from scratch). W is not measured energy in joules; it is a Lyapunov-type bookkeeping quantity built from the model's own terms, useful precisely because a correct integrator must hold it flat. Figure 3.3 runs forward Euler and semi-implicit Euler on the undamped machine and watches W: forward Euler drifts, semi-implicit does not.

3.4 Why semi-implicit Euler and RK4 do not have this problem

Semi-implicit Euler updates Δω with the old angle and then δ with the new Δω. That one-line reordering makes the map area-preserving (symplectic) in the (δ, Δω) plane for the undamped oscillator, so W cannot drift monotonically — it can only ripple around its true value. The bound on that ripple holds for hωn < 2, where ωn = |λ| = 8.9618 rad/s is the undamped natural frequency of the linearised mode, giving h < 2/8.9618 = 0.2232 s for the undamped (KD = 0) linear oscillator. With KD = 2 restored, the linearised semi-implicit map reaches spectral radius 1 (the larger eigenvalue magnitude of the one-step map) at h = 0.2196 s — about 62 times forward Euler's 3.56 ms limit for the same eigenvalue, at the same one function evaluation per step. RK4's stability boundary for a purely oscillatory mode is the well-known h|λ| < 2√2 ≈ 2.828; the small negative σ here shifts it slightly, to h|λ| = 2.86, i.e. h < 2.86/8.9618 = 0.3191 s, about 90 times forward Euler's limit, at four function evaluations per step. Figure 3.1 draws the forward-Euler part of this: forward Euler is stable exactly when hλ lands inside the disc of radius 1 centred at −1 in the complex plane.

The transient starts at amplitude 1.94° (the gap between the old and new equilibrium angles, 28.21° and 30.15°). Forward Euler should show that amplitude decaying toward zero, as the true system and Lesson 2's eigenvalue both say it must. Instead, over seconds 8–10 its oscillation is still 22.3° wide — more than eleven times the starting amplitude, growing, not shrinking — while semi-implicit Euler and RK4 both land on 0.609°, agreeing with each other to three figures using one and four function evaluations per step respectively. Left running to 60 s, forward Euler's growing oscillation eventually carries δ past 180° at t = 16.93 s, which is exactly the opening problem's number. That crossing is a property of the Euler map at this step, not of the machine.

4.1 The energy check

A second listing (lesson3_exercises.py, shipped beside this page; §6 quotes its output) sweeps step size and larger RK4 steps to confirm the thresholds of §3, and the figure below runs the undamped (KD = 0) machine for 10 s at h = 10 ms under forward Euler and semi-implicit Euler, tracking ΔW(t) = W(t) − W(0) with W(0) = −1.9098 (from §3.3, evaluated at δ0, Δω = 0, Pm = 0.85 pu).

The full code:

"""Forward Euler, semi-implicit Euler, and RK4 on the SMIB swing
equation: which one lies about stability at h = 10 ms?

Swing convention: 2H d(dw)/dt = P_m - P_e - K_D dw
                   d(delta)/dt = omega_0 dw
Stdlib only. Run: python lesson3_euler_drift.py
"""
import cmath
import math

H = 3.5
K_D = 2.0
OMEGA_0 = 2.0 * math.pi * 60.0
P_MAX = 1.1 * 1.0 / 0.65


def f(x, p_m, k_d=K_D):
    delta, dw = x
    ddelta = OMEGA_0 * dw
    ddw = (p_m - P_MAX * math.sin(delta) - k_d * dw) / (2.0 * H)
    return (ddelta, ddw)


def equilibrium(p_m):
    delta = math.asin(p_m / P_MAX)
    k_s = P_MAX * math.cos(delta)
    a10, a11 = -k_s / (2.0 * H), -K_D / (2.0 * H)
    disc = cmath.sqrt(a11 * a11 + 4.0 * a10 * OMEGA_0)
    return delta, (a11 + disc) / 2.0


def euler_step(x, p_m, h):
    dx = f(x, p_m)
    return (x[0] + h * dx[0], x[1] + h * dx[1])


def semi_implicit_step(x, p_m, h):
    delta, dw = x
    ddw = (p_m - P_MAX * math.sin(delta) - K_D * dw) / (2.0 * H)
    dw_new = dw + h * ddw
    return (delta + h * OMEGA_0 * dw_new, dw_new)


def rk4_step(x, p_m, h):
    k1 = f(x, p_m)
    x2 = (x[0] + 0.5*h*k1[0], x[1] + 0.5*h*k1[1])
    k2 = f(x2, p_m)
    x3 = (x[0] + 0.5*h*k2[0], x[1] + 0.5*h*k2[1])
    k3 = f(x3, p_m)
    x4 = (x[0] + h*k3[0], x[1] + h*k3[1])
    k4 = f(x4, p_m)
    dd = (k1[0] + 2*k2[0] + 2*k3[0] + k4[0]) / 6.0
    dw = (k1[1] + 2*k2[1] + 2*k3[1] + k4[1]) / 6.0
    return (x[0] + h*dd, x[1] + h*dw)


def late_amplitude(step_fn, delta0, delta_new, p_m, h, t_end):
    x = (delta0, 0.0)
    n = int(round(t_end / h))
    amp = 0.0
    for i in range(n):
        x = step_fn(x, p_m, h)
        t = (i + 1) * h
        if 8.0 <= t <= 10.0:
            amp = max(amp, abs(x[0] - delta_new))
    return math.degrees(amp)


def slip_time(delta0, p_m, h, t_end):
    x = (delta0, 0.0)
    n = int(round(t_end / h))
    for i in range(n):
        x = euler_step(x, p_m, h)
        if abs(x[0]) > math.pi:
            return (i + 1) * h
    return None


def main():
    delta0, lam = equilibrium(0.8)
    sigma, omega_d = lam.real, lam.imag
    print("lambda = %.4f %+.4fj 1/s (sigma, omega_d)" % (sigma, omega_d))

    h = 0.01
    mag = abs(1.0 + h * lam)
    growth = math.log(mag) / h
    print("h = %.3f s: |1 + h*lambda| = %.5f" % (h, mag))
    print("Euler growth rate  = %+.3f 1/s (physical = %+.3f 1/s)" %
          (growth, sigma))
    print("Euler amplitude x10s  = %.3f" % (mag ** (10.0 / h)))
    print("True amplitude x10s   = %.3f" % math.exp(sigma * 10.0))

    h_crit = -2.0 * sigma / (sigma * sigma + omega_d * omega_d)
    print("h_crit (formula) = %.5f s = %.2f ms" % (h_crit, h_crit * 1000))

    lo, hi = 0.0001, 0.02
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        if abs(1.0 + mid * lam) < 1.0:
            lo = mid
        else:
            hi = mid
    print("h_crit (bisection) = %.5f s = %.2f ms" % (lo, lo * 1000))

    h1 = 0.001
    mag1 = abs(1.0 + h1 * lam)
    print("h = %.3f s: Euler amplitude x10s = %.3f" %
          (h1, mag1 ** (10.0 / h1)))

    p_m_new = 0.85
    delta_new, _ = equilibrium(p_m_new)
    amp0 = math.degrees(delta_new - delta0)
    print("\nInitial amplitude |delta_new - delta0| = %.2f deg" % amp0)
    for name, step_fn in (("forward Euler", euler_step),
                           ("semi-implicit Euler", semi_implicit_step),
                           ("RK4", rk4_step)):
        amp = late_amplitude(step_fn, delta0, delta_new, p_m_new, 0.01, 10.0)
        print("%-20s late amplitude (8-10 s) = %.3f deg" % (name, amp))

    t_slip = slip_time(delta0, p_m_new, 0.01, 60.0)
    print("\nForward Euler, h = 10 ms, run to 60 s:")
    print("slip time (|delta| > 180 deg) = %.2f s" % t_slip)


if __name__ == "__main__":
    main()

5. Model limits

Everything above is exact only for the linearised machine: one fixed eigenvalue λ, valid near δ0 = 28.21°. The full nonlinear swing equation has −Pmaxsinδ on its right-hand side, and its local eigenvalue changes as δ moves along the trajectory — by Lesson 2's eigenvalue formula applied at Pm = 0.85 pu the eigenvalue's oscillatory part alone shifts from ωd = 8.9607 to about 8.876 rad/s at the new equilibrium, a small but real change. Once forward Euler's error has grown large enough to carry δ far from either equilibrium — which is exactly what happens between t = 11 s and the 16.93 s slip — the linear analysis of §3 no longer describes the trajectory at all; §3's numbers explain why the divergence starts, not the exact shape of the runaway once it is underway. Variable-step (adaptive) solvers exist precisely to catch a growing local error and shrink h automatically; this lesson deliberately keeps every step fixed so the reader can see the raw error grow instead of having a solver hide it. Exercise 4 asks what a programmer should check before trusting an adaptive tool's own "unstable" verdict.

6. Exercises

1. Computational — find h_crit by bisection

Using only the linear test equation and this eigenvalue, bisect on h to find the largest forward-Euler step for which the linearised machine still decays.

Answer target

3.56 ms. lesson3_exercises.py bisects 60 times between 0.1 ms and 20 ms and prints h_crit = 0.00356 s = 3.56 ms, matching §3.2's closed form exactly.

2. Derivational — derive dW/dt

Starting from 2H d(dw)/dt = P_m - P_e - K_D dw and d(delta)/dt = omega_0 dw, derive dW/dt = −KDω0 Δω².

Answer target

Multiply the first equation by ω0Δω, use dδ/dt = ω0Δω to rewrite the left side as H d(ω0Δω²)/dt, and the (Pm − Pmaxsinδ)dδ/dt term as +d/dt[Pmδ + Pmaxcosδ], which moves to the left side with a minus sign to form W; the remaining −KDω0Δω² term is exactly the claimed result. See §3.3 for the full steps.

3. Computational — RK4 at larger steps

Run RK4 at h = 0.1, 0.2, 0.3, 0.35 s and report where it stops decaying.

Answer target

Between 0.3 s and 0.35 s, matching §3.4's value of 0.319 s for the base-point eigenvalue (the simulation settles at the Pm = 0.85 pu eigenvalue, whose RK4 limit is 0.322 s — also inside the bracket). lesson3_exercises.py runs each step size to max(10, 6/h) s (60, 30, 20 and 17.1 s) and takes the largest |δ − δnew| over the last 2 s. It reports late amplitudes of 0.0001°, 0.0000° and 0.0000° at h = 0.1, 0.2, 0.3 s (decaying) against 101545.2096° at h = 0.35 s (diverging). The near-zero values at 0.2 s and 0.3 s include strong RK4 numerical damping (|R| well below eσh), so "decaying" there means stable, not accurate.

4. Conceptual — a tool reports "unstable"

A simulation tool reports a machine "unstable" at a 20 ms step. List two checks before believing it.

Answer target

(1) Halve the step and re-run: if the "instability" shrinks or disappears, it was the integrator, not the machine (§3.1– §3.2 show this exact pattern at 10 ms versus 1 ms). (2) Compute |1 + hλ| (or the method's own amplification factor) for the model's fastest eigenvalue at that step, independent of running any simulation at all — this is the check §1 asks for "before trusting a plot".

5. Computational — how close to the true value 0.240?

Plot the forward-Euler 10 s amplitude factor against h from 1 ms to 10 ms. Show that it never reaches the true value 0.240 for any h > 0, and find the step at which it is within 10% of 0.240.

Answer target

The run's values, from lesson3_exercises.py : 1 ms→0.358, 2 ms→0.535, 3 ms→0.799, 4 ms→1.194, 5 ms→1.784, 6 ms→2.665, 7 ms→3.979, 8 ms→5.938, 9 ms→8.858, 10 ms→13.203. Expanding ln|1 + hλ| = hσ + (h²/2)(ωd² − σ²) + O(h³) gives a 10 s factor of about 0.240·e5h(ωd² − σ²), which is above 0.240 for every h > 0 (at 1 ms: 0.240·e0.401 = 0.358), so there is no crossing. The factor is within 10% of 0.240 (below 0.264) only for h < 0.237 ms — forward Euler is measurably inaccurate for this mode at any step a working engineer would consider "small".
